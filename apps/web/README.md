# Next.js Frontend

## Project Overview
This directory contains the Next.js frontend application for the fundraising platform. It is built with TypeScript and Tailwind CSS.

## Core Setup
- [ ] Initialize Next.js with TypeScript, Tailwind
- [ ] Configure shadcn-ui (`npx shadcn-ui@latest init`)
- [ ] Set up absolute imports (`@/*`)
- [ ] Add global styles (`styles/globals.css`)
